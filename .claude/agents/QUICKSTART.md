# AFL Agent Team — Quick Start Guide

## Your Virtual Team for andrewfranklinleo.com

10 specialized AI agents, each loaded with complete platform context: tech stack, content library, revenue strategy, brand identity, and all 70+ Invention Tools documents.

## Agents at a Glance

| Agent | Role | Activate When |
|---|---|---|
| **AFL Orchestrator** | Master pipeline coordinator | Starting a new phase or multi-agent workflow |
| **AFL Frontend Developer** | Next.js/React/Tailwind UI specialist | Building or modifying pages, components, styles |
| **AFL Backend Architect** | Firebase/Stripe/API infrastructure | API routes, auth, payments, database |
| **AFL Content Strategist** | Content creation from Invention Tools | Writing essays, newsletters, case studies |
| **AFL Growth Hacker** | Revenue growth and distribution | Subscriber acquisition, referral optimization |
| **AFL Brand Guardian** | Brand identity and consistency | Design reviews, voice checks, visual audits |
| **AFL Revenue Operator** | 9 revenue stream management | Pricing, pipeline, unit economics |
| **AFL Reality Checker** | QA and evidence-based validation | Pre-launch testing, route verification |
| **AFL Governance Analyst** | AI governance domain intelligence | Regulatory analysis, intelligence products |
| **AFL Executive Summary** | Board-level business communications | Investor briefs, status reports, stakeholder comms |
| **AFL Sprint Prioritizer** | Feature sequencing and execution | Sprint planning, backlog prioritization |

## Quick Activation

### Full Pipeline (Launch Sequence)
Activate `afl-orchestrator` and say:
> "Run the full launch pipeline for andrewfranklinleo.com. We need Firebase credentials configured, Stripe products created, and Vercel deployment completed."

### Build a New Page
Activate `afl-frontend-developer` and say:
> "Build a new page at /[route] that [description]. Follow the existing design system."

### Write New Content
Activate `afl-content-strategist` and say:
> "Write a new framework essay on [topic] using content from [specific Invention Tools document]."

### Revenue Check
Activate `afl-revenue-operator` and say:
> "Analyze current revenue performance against Phase 1 targets. Identify the highest-impact action to take this week."

### Pre-Launch QA
Activate `afl-reality-checker` and say:
> "Run the full reality check on the platform. Test all 27 routes, all API endpoints, and mobile responsiveness."

### Brand Audit
Activate `afl-brand-guardian` and say:
> "Audit the platform for brand consistency. Check colors, typography, voice, and CTA placement across all pages."

### Create Intelligence Content
Activate `afl-governance-analyst` and say:
> "Write this week's Obligation Intelligence newsletter. Focus on [regulatory development or governance topic]."

### Sprint Planning
Activate `afl-sprint-prioritizer` and say:
> "Plan the next 2-week sprint. Use RICE scoring to prioritize the backlog."
