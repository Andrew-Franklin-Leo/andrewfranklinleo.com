# Aureya and Frankmax Product Catalog

The Aureya and Frankmax product families represent the consumer-facing and enterprise-facing surfaces of the **AINEFF** (AI Network of Engineered Frankmax Functions) autonomous ecosystem. Every product in this catalog is designed to operate independently while contributing to a unified, self-reinforcing network governed by the **ORF Protocol** and orchestrated through **Tower Control**.

This page organizes all products by functional category, summarizes their purpose, and maps the integration points that make the ecosystem more valuable than any single tool.

Data flows between products through the **AINEG** (AI Network of Engineered Governance) data bus, ensuring that work done in one product enriches the entire ecosystem.

## Governance and the ORF Protocol

Every Aureya product operates under the governance framework defined by the **ORF Protocol**. This means:

1. **Atomic Constraints** are enforced at every layer of the **15-Layer Reality Stack**, from model inference through user interaction.
2. **Pre-Incident Governance** is built into product design, not bolted on after deployment.
3. **Obligation Intelligence** flows through the **AINEG** data bus, ensuring that governance decisions in one product propagate across the ecosystem.
4. **The Fragility Codex** informs risk boundaries for each product, calibrating autonomy levels to the sensitivity of the task domain.
5. **Performance Tokens** track and reward productive use across all products, creating an economic layer that aligns user incentives with ecosystem health.

The **Constraint Council** provides ongoing oversight, reviewing product behavior against the governance framework and issuing binding guidance through Governance Signals.

## Revenue Model Summary

The Aureya ecosystem follows a consistent monetization pattern across all products:

- **Free tier** provides genuine utility to attract users and build ecosystem lock-in
- **Pro/Individual tiers** ($5-$29/month) unlock higher limits, advanced features, and cloud capabilities
- **Team/Business tiers** ($7-$75/seat/month) add collaboration, administration, and compliance features
- **Enterprise tiers** (custom pricing) provide dedicated infrastructure, SLAs, and governance controls

Total addressable revenue across all products at scale exceeds the targets outlined in the platform's nine revenue streams. Each product reinforces the others, creating compounding network effects measured by the **Power Concentration Index (PCI)**.
